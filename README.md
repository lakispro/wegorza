# Zlewnia Węgorzy – 72,6 czy 57,3 km²?

Strona: https://wegorza.lakis.pro (GitHub Pages z katalogu `docs/`).

Wyjaśnienie rozbieżności między powierzchnią zlewni Węgorzy (dopływ Łeby) wg Wód Polskich (72,6 km²)
a wartością z Wikipedii (57,3 km², różnica z tabeli dla Łeby w opracowaniu IMGW 2003/2004 opartym na
„Podziale Hydrograficznym Polski” 1983). Kopie źródeł w `docs/zrodla/`, geometrie w `docs/data.geojson`.
